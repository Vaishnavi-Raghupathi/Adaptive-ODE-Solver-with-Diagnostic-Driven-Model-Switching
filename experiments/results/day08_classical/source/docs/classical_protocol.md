# Day 8: bounded classical benchmark controls

Written before the Day 8 run. Use `experiments/configs/day08_classical.json` without tuning to final scores. Benchmark Lorenz, Van der Pol, Robertson, and the original misspecified oscillator on their built-in spans/initial states, 301 samples, chronological 60/20/20 split. Use RK4, RK45, DOP853, BDF, Radau, LSODA; include linear-oscillator calibration only for the mismatch case, where it is applicable. No ML or PINN comparison is claimed in this control suite.

The known-equation reference uses the built-in tight-tolerance reference method (rtol=1e-11, atol=1e-13), except mismatch uses the analytical solution. Cross-check against an alternative tight solver (Radau for Lorenz; DOP853 for Van der Pol; BDF for Robertson; DOP853 for mismatch), with a larger 1,000,000 RHS-evaluation budget for reference generation. Record reference disagreement rather than calling every numerical reference exact. Candidate predictions have a 50,000 RHS-evaluation budget; record exhaustion or instability as failures. Full-trajectory prediction failures exclude a candidate from selection because it cannot return a finite complete trajectory; this is a robustness eligibility check, not selection based on final test error.

Repeat each deterministic benchmark three times for timing observations, not independent scientific samples. Selection uses validation MSE only; test scores and raw-state residual summaries are post-selection reports. There is no pooled accuracy score across systems. This suite checks the library's numerical behavior and failure accounting, not general proof of optimal solver selection or superiority to established libraries. Tighter references and lower raw MSE are not automatically more cost-effective choices.
