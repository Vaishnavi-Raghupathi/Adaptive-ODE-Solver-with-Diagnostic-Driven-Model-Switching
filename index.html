Adaptive ODE Solver

Diagnostic-driven model switching for Lorenz dynamics using a classical ODE solver and Neural ODE.

Scenarios

Clean Data

No added noise and no mismatch; classical solver should generally be sufficient.

Noisy Data

Measurement noise is added while dynamics stay fixed to test robustness.

Model Mismatch

True dynamics vary over time, while classical fitting assumes fixed dynamics.

Project

The pipeline runs residual diagnostics and automatically chooses between classical_ok and neural_ode.
